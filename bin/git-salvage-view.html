From git's reflog and git-salvage's snapshots. Select an entry to see it in the graph.

    How to read this
    • A commit is a saved version of the whole project. Each one points back at the commit(s) it was made on top of; the lines show that.
    • A branch is only a name pointing at one commit. Committing moves it forward. reset and rebase move it elsewhere.
    • HEAD is where you are: usually a branch; if it points straight at a commit, HEAD is detached.
    • Commits no branch points at any more are left behind. git keeps them in the reflog for a while (30 days by default, then git gc may delete them), so they can still be rescued.
    • Changes you never committed live only in the index and the working tree. git cannot bring those back; git-salvage snapshots them before commands that would destroy them.
